## 核心交付

输入讲稿后，通过真实 OpenAI API 生成四类学习材料；显示对应原文；支持答题、卡片复习和重新生成；明确处理空输入、短输入及生成失败。

计划技术栈：Next.js、TypeScript、Tailwind CSS、shadcn/ui、OpenAI Responses API、Zod、Vercel。

演示讲稿可以预置，生成结果必须现场处理。API 密钥仅保存在服务端环境变量中，不提交到 GitHub。
